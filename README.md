# Data Structures

A interactive command-line interface (CLI) educational tool built in Java designed to demonstrate fundamental computer science data structures and sorting algorithms.

## Overview

**Data Structures** provides an interactive learning sandbox for inspecting core computer science structures. Built into a dynamic, console-driven execution framework, it guides users through configuring multi-dimensional storage arrays, linked lists, linear pipelines, structural trees, and graph search implementations—all manipulated entirely via command inputs.

## Features

- **Multi-Dimensional Array Operations:** Interactive controls to instantiate, sort, delete, and inspect elements inside 1D, 2D, Triangular, Jagged, and 3D array frameworks.
- **Dynamic Linked Lists:** Complete structural implementations of Single, Double, and Circular Linked Lists featuring index lookups, modifications, and linear element removals.
- **Stacks & Queues:** Provides dual underlying construction representations for sequential collections—enabling operations using either standard fixed arrays or dynamic linked nodes.
- **Sorting & Search Sandbox:** Hands-on playground comparing time complexities across standard algorithm implementations including Bubble Sort, Merge Sort, Quick Sort, Linear Search, and Binary Search.
- **Advanced Graph & Tree Topologies:** Interactive node maps supporting full tree traversals (In-Order, Pre-Order, Post-Order, Level-Order) along with structural Graph search utilities (DFS and BFS).

## Tech Stack

- **Language:** Java (JDK 8 or higher)
- **Input System:** Standard Scanner (`java.util.Scanner`)
- **IDE Environment:** IntelliJ IDEA (`.idea` configuration mappings)

## Setup & Execution

### Prerequisites

- Java Development Kit (JDK) 8 or higher configured within your machine path environments.

### Installation

- Clone the repository directory structure locally:

  ```bash
  git clone https://github.com
  ```

- Enter the source tree shell folder and compile the clean bytecode configurations:

  ```bash
  cd data-structures/src
  javac Main.java
  ```

- Fire up the console guide engine to explore available algorithms interactively:
  ```bash
  java Main
  ```
